# Screenshots

Place screenshot images in this directory for use in the README.

Recommended naming convention:
- `home.png` - Home page screenshot
- `playlists.png` - Playlists page screenshot  
- `burn.png` - Burn workflow screenshot
- `settings.png` - Settings page screenshot

## Usage in README

Reference screenshots in the README like this:

```markdown
![Home Page](docs/screenshots/home.png)
```
